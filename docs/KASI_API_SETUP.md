# 한국천문연구원 음양력 API 연동 준비

공식 자료: https://www.data.go.kr/data/15012679/openapi.do

## 현재 구현
- `src/lib/kasi-lunar.ts`: 양력 날짜로 KASI `getLunCalInfo` 조회
- `KASI_SERVICE_KEY` 환경변수가 없거나 오류가 발생하면 `null` 반환
- XML 응답의 성공 코드, 요청한 양력 날짜와의 일치, 음력 월 길이(29/30), 윤달 구분(평/윤)을 확인
- 인증키는 서버 전용이며 클라이언트에 노출하지 않음
- 아직 이 모듈은 고객의 사주팔자 계산이나 상담 API에 연결되지 않음

## 운영 전 필수 작업
1. 공공데이터포털에서 한국천문연구원 음양력 정보 API 활용 신청 및 서비스키 발급
2. Vercel 서버 환경변수 `KASI_SERVICE_KEY`에 **디코딩된** 키를 저장하고 재배포
3. 개발 환경에서 `npm run test:kasi`, `npm run test:birth`, `npx tsc --noEmit`, `npm run build` 통과 확인
4. 실제 API로 양력→음력 응답 및 윤달 경계, 29/30일 사례 검증
5. 음력→양력 변환은 별도 공식 엔드포인트의 입력·응답 명세를 검증한 뒤 구현
6. 절기 시각, 연주·월주·일주·시주 계산 및 경계 정책을 독립 기준과 비교한 뒤 개인 상담에 연결

## 주의
공식 API가 제공하는 월건·세차·일진을 사주 명식의 절기 기준 연주·월주·일주와 무조건 동일하다고 가정하지 않는다. 한국 표준시, 역사적 시간대, 자시 경계, 출생시각 미상 정책을 검증하기 전에는 개인 명식을 출력하지 않는다.

공공데이터포털의 API 호출 한도 및 운영 승인 조건을 확인한다. 외부 API 호출 실패 시 가짜 결과를 만들지 않는다.
