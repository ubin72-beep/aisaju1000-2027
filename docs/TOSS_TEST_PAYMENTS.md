# 토스페이먼츠 테스트 결제 연동 준비

## 보안
- 화면 캡처에 테스트 시크릿 키 및 보안 키가 노출되었습니다. 토스페이먼츠 개발자센터에서 해당 키를 재발급/교체하세요.
- 키 원문을 GitHub, 채팅, 스크린샷 또는 클라이언트 소스에 저장하지 마세요.
- Vercel 서버 환경변수 `TOSS_SECRET_KEY`에는 새로 발급한 **test_gsk_** 시크릿 키를 저장합니다.
- 클라이언트 키 `test_gck_`는 추후 SDK 결제창 구현에만 사용합니다.
- `TOSS_TEST_PAYMENTS_ENABLED=true`가 없으면 승인 API는 항상 503을 반환합니다. **운영에서는 설정하지 마세요.**
- 이 구현은 실결제 키(`live_`)를 거부합니다.

## 현재 범위
- `supabase/payment_orders.sql`: 주문 원장과 회원별 읽기 전용 RLS. 서비스 역할로만 주문 생성/상태 변경 가능.
- `POST /api/payments/toss/confirm`: 인증 회원, 주문 소유자, 저장된 금액, 주문 상태 확인 후 토스 승인 API 호출.
- 응답 검증 및 결제 기록 저장. 네트워크 오류 또는 승인 후 저장 실패 가능성이 있으면 재결제 대신 수동 확인 필요.
- **결제 상품, 가격, 주문 생성 API, SDK 결제 UI, 포인트 지급, 취소/환불, 웹훅은 아직 미구현**. 따라서 고객에게 결제 버튼을 노출하지 않음.
