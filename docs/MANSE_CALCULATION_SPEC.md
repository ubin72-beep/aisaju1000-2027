# 천년지기 만세력 계산 엔진 개발 명세

## 원칙
AI 언어모델이 사주팔자를 추측하거나 생성하지 않는다. 검증된 역법 계산 결과만 개인 사주 상담의 근거로 전달한다. 계산 결과가 검증되지 않았거나 입력 정보가 불충분하면 일반 명리 상담으로 제한한다.

## 입력
- 양력/음력 구분, 윤달 여부, 생년월일, 출생시각(선택)
- 출생지와 적용 시간대: 현재 UI는 국내 출생 가정. 향후 해외 출생 및 역사적 시간대 보정 지원
- 출생시각 미상은 시주를 계산하지 않음
- 음력 윤달은 실제 해당 연도에 존재하는 윤달인지 확인

## 계산 파이프라인
1. 입력 날짜 검증 (양력 윤년 / 음력 월 길이 / 윤달 유효성)
2. 공인된 한국 음양력 기준과 대조하여 음력→양력 변환
3. 절기 시각 기준 연주·월주 계산. 입춘 및 절입 경계 시각 테스트
4. 기준일이 명시된 일주 계산 및 날짜 변경 경계 정책 확정
5. 출생시각·시간대·자시 경계 정책에 따른 시주 계산
6. 천간·지지·오행·십성 도출
7. 계산 버전·근거·불확실성·적용 정책 기록

## 필수 검증 사례
- 입춘 직전/직후 출생 (연주 경계)
- 매월 절입 직전/직후 출생 (월주 경계)
- 23시~01시 자시 경계 및 일주 변경 정책
- 윤달이 있는 연도와 없는 연도
- 음력 29일·30일과 잘못된 날짜
- 출생시각 미상 (시주 미표시)
- 1900년대 역사적 시간대 변화와 해외 출생
- DST 적용 기간 및 일광절약시간 경계

## 서비스 연결 게이트
- 출처가 명확한 만세력/역법 데이터 또는 검증된 라이브러리 선정
- 독립된 기준 자료와 경계값 회귀 테스트 통과
- 개인 사주 API는 서버에서만 계산하고 본인 인증·권한 검사
- 고객 화면에 사용된 달력·시간대·계산 정책과 불확실성 표기
- 검증 전까지 현재 AI 교육 상담 프롬프트를 유지하고 개인 명식 사용 금지

## 현재 상태 (2026-11)
출생 정보 저장 및 기본 입력 검증만 제공. 음력 실제 월 길이, 윤달 존재 여부, 절기, 사주팔자 계산은 미구현. 개인 명식 기반 유료 상담은 활성화하지 않는다.
