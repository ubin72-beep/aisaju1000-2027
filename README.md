# AI 사주 천년지기 2027 — 신규 구축 시작본

기존 `aisaju-2026` 저장소와 분리해 새로 개발하기 위한 Next.js 시작 프로젝트입니다.

## 실행
1. Node.js 20 이상 설치
2. `npm install`
3. `npm run dev`
4. 브라우저에서 http://localhost:3000 열기

## 현재 포함
- 프리미엄 네이비·샴페인 골드 메인 화면
- 서비스 소개 및 포인트 충전 상품 UI
- 상담 유형별 고정 포인트 가격 안내
- 로그인/회원가입 진입 화면(현재 UI 시안)
- 마이페이지 및 관리자 화면의 초기 UI

## 아직 연결되지 않은 기능
이 저장소는 첫 화면과 화면 구조를 확인하기 위한 프런트엔드 시작본입니다.
실제 회원 인증, PostgreSQL 데이터베이스, 만세력 계산 엔진, AI API, 토스페이먼츠 승인/취소,
포인트 원장 및 관리자 권한은 후속 서버 개발과 키/가맹점 설정이 필요합니다.
실제 결제나 포인트 지급이 되는 것으로 표시하지 마세요.

## 다음 개발 순서
1. PostgreSQL 스키마와 마이그레이션
2. 회원 인증 및 역할 기반 접근 제어
3. 만세력 엔진 검증 및 사주 프로필
4. 포인트 원장(트랜잭션/멱등성/동시성 제어)
5. 토스페이먼츠 서버 승인·취소 웹훅 연동
6. AI 상담 및 정상 응답 완료 후 차감/실패 복구
7. 관리자 감사 로그와 운영 통계
8. 개인정보·약관·환불 정책 검토 및 보안 테스트
