# AI 사주 천년지기 2027

프리미엄 AI 명리학 상담 플랫폼의 신규 프로젝트입니다.

## 기술 구성(초기안)
- Next.js 15 / React
- PostgreSQL
- OpenAI API
- 별도 검증된 만세력 엔진
- Toss Payments
- Vercel 배포

## 초기 화면 시안
- 홈 화면 및 서비스 소개
- 로그인 / 회원가입 화면
- 마이페이지
- 관리자 대시보드 화면
- 포인트 충전 및 상담별 포인트 안내

## 구현 상태 안내
현재 화면은 디자인 및 프로젝트 구조를 확인하기 위한 초기 시안입니다. 실제 회원 인증, DB 연동, 만세력 계산, AI 상담, 결제 승인, 포인트 원장, 관리자 권한 검증은 아직 구현되지 않았습니다.

실서비스 오픈 전에는 개인정보 보호, 결제 검증, 포인트 원장 및 환불 처리, 관리자 접근통제 등을 서버 측에서 구현하고 테스트해야 합니다.

## 로컬 실행
```bash
npm install
npm run dev
```

환경 변수 예시는 `.env.example`을 참고하세요. 실제 비밀키는 저장소에 올리지 말고 배포 환경의 Secret 설정에 등록하세요.
